"Strings," Eldrin said, lifting a glowing scroll from the shelf, "are how your code speaks. Every message, every name, every sentence — stored as a String."
🧙
Archmage Eldrin
A String is a sequence of characters wrapped in double quotes. Think of it as a labelled jar containing text rather than numbers. You declare one just like any other variable.
✦ String declaration
String name = "Eldrin";
String greeting = "Welcome to the Academy!";
System.out.println(greeting);

Strings in Java are objects, not primitives. They are declared with a capital String and hold any sequence of characters.

● ● ●
String s = "Hello, World!";
System.out.println(s.length()); // 13
System.out.println(s.toUpperCase()); // HELLO, WORLD!

Use + to concatenate (join) strings: "Hello" + " " + "World" → "Hello World".
